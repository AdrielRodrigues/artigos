# Key Concepts

Reference notes synthesizing the core concepts needed to read this collection of papers on machine learning for optical networks — spanning intelligent network resource allocation, failure/QoT management, short-reach system equalization, hollow-core fiber transport, and accelerated RL research tooling.

## System Architecture for ML-Enabled Optical Networks
An intelligent optical network module comprises Functional Elements — Data Collection and Data Processing — that interface between the physical network and an ML agent, gathering raw telemetry (optical power, spectrum occupancy, traffic matrices) and preprocessing it into structured features. This closed-loop architecture (data collection → ML inference → network reconfiguration) is the common substrate underlying nearly all ML applications in this collection, enabled by SDN/SDON control planes, model-driven telemetry (gRPC/YANG), and embedded monitoring devices like OTDR.

## Three ML Application Paradigms: Regression, Classification, Decision-Making
Every ML use case in optical networks falls into one of three paradigms. Regression and classification are typically solved with supervised or unsupervised learning: a model trained offline on labeled/unlabeled data produces continuous (regression) or categorical (classification) outputs from live features. Decision-making problems instead use reinforcement learning, where an agent iteratively chooses network actions and updates its policy from a reward signal. Resource allocation (routing, spectrum assignment) is usually cast as decision-making; monitoring and prediction (traffic, QoT, OSNR) are cast as regression/classification.

## Motivations for Applying ML in Optical Networks
Four factors justify ML over classical analytic/heuristic methods: historical data utilization (ML absorbs accumulated statistics and is more noise-robust than current-state-only heuristics); reduced online computation (expensive training happens offline, leaving fast inference for real-time reconfiguration); reduced feature engineering (deep learning automatically extracts features from raw data like eye diagrams where no explicit analytic relationship exists); and enabling technologies (SDON programmability, model-driven telemetry, mature DSP/OTDR devices making data collection and deployment practical).

## Classical Supervised/Unsupervised ML Toolbox (SVM, ANN/CNN/RNN, K-means, PCA)
Support Vector Machines find maximum-margin hyperplanes (with kernel tricks for non-linear boundaries) for classification tasks like failure prediction and QoT/BER classification. Neural networks specialize by data structure: CNNs suit image-like inputs (eye diagrams, sampled waveforms); RNN/LSTM suit sequential data (traffic history, temporal degradation trends); generic ANN/DNN suit feature-to-target mappings (OSNR estimation, RWA configuration). K-means clustering visualizes/groups unlabeled samples (e.g., BER trend clusters for failure localization) and PCA compresses high-dimensional inputs (e.g., delay-tap diagrams) before downstream estimation, reducing computational load relative to raw inputs.

## Reinforcement Learning and Deep Reinforcement Learning (RL/DRL) Formalism
RL models sequential network decisions as a Markov Decision Process (states, actions, transition probabilities, rewards), with an agent seeking a policy maximizing expected discounted return via value functions V(s)/Q(s,a); Q-learning updates Q-values model-free via the Bellman equation, and ε-greedy balances exploration/exploitation. DRL replaces the tabular Q-table with deep networks (CNN/RNN-based) to handle realistic optical-network state/action spaces too large for lookup tables, and is the dominant paradigm for routing, resource allocation, and equalizer/network control tasks throughout this collection.

## Traffic and Resource Requirement Prediction
ML-based traffic prediction exploits the regularity/periodicity of network traffic to forecast future bandwidth demand or resource needs from historical data, enabling proactive rather than reactive provisioning. Sequence-aware models (LSTM, NARNN) are favored since traffic is inherently time-series, and applications range from inter/intra-datacenter bandwidth forecasting to PON-specific bandwidth-request prediction (k-NN, feed-forward ANN, XGBoost) supporting dynamic bandwidth allocation (DBA) for ONUs.

## Supervised and Reinforcement-Learning-Based Routing
Routing can be framed as classification/regression, mapping network/traffic state to a pre-computed optimal route (via Bayesian probabilistic routing models or DNN/logistic-regression classifiers selecting among pre-computed plans), replacing costly online ILP solves with millisecond-scale inference. RL-based routing instead maintains per-node Q-tables (or multi-agent shared tables) to select next-hop links minimizing burst loss in Optical Burst Switching networks, with deflection routing (RLDRS, IRLRCR, PQDR) rerouting contended bursts via the next-best link rather than dropping them, trading delay for lower loss.

## Routing and Wavelength/Spectrum Assignment (RWA/RSA) and Virtual Optical Network Embedding (VONE)
RWA (fixed-grid WDM) assigns a route and wavelength per demand; RSA (elastic optical networks, EONs) assigns a route and a contiguous, continuous block of frequency slot units (FSUs), both NP-complete problems traditionally solved via ILP or heuristics. VONE extends this to provisioning entire virtual network topologies (multiple nodes/links with compute and bandwidth requirements) rather than single point-to-point connections, requiring joint node mapping and path/spectrum mapping — central to Infrastructure-as-a-Service optical offerings.

## Single-Agent DRL with Multi-Step Invalid Action Masking for VONE
Where prior VONE work split node-allocation and link-allocation across multiple cooperating agents (assuming the combined action space was too large for one agent), a single agent with an enlarged action space plus multi-step invalid action masking — restricting choices to only currently feasible actions across sequential sub-decisions within one timestep — achieves lower blocking probability with simpler training than multi-agent decompositions, since sub-agents in the split approach cannot jointly optimize.

## Proximal Policy Optimization (PPO)
PPO is a policy-gradient DRL algorithm that constrains policy updates to a trust region around the current policy, improving training stability over unconstrained policy gradients. It is the standard base algorithm for discrete/structured optical-network action spaces (VONE, RSA), used both in conventional CPU-based training and reimplemented in JAX for GPU/TPU-accelerated training.

## Heuristic Benchmarking Rigor (Node-Mapping + Path-Mapping Components, KSP-FF)
State-of-the-art VONE/RSA heuristics decompose into interchangeable components — a node-mapping strategy (e.g., CaLRC, NSC, TMR) and a path/spectrum-mapping strategy (e.g., kSP-FF, kSP-FDL, MSP-EF) — that can be recombined and cross-benchmarked systematically rather than compared against one arbitrarily-chosen baseline, addressing a documented gap where prior DRL papers under-tuned their heuristic comparisons.

## Blocking Probability and Interpretability via Utilization Heatmaps
Blocking probability — the fraction of arriving requests rejected due to insufficient resources — is the standard metric for comparing allocation strategies under dynamic Poisson-arrival/exponential-holding-time traffic. Visualizing normalized link-by-FSU utilization heatmaps over an evaluation episode shows why learned agents outperform heuristics: heuristics concentrate load on specific links (always picking the first available slot) while agents distribute load more evenly, providing a concrete, reusable interpretability technique for network-control policies.

## GPU/TPU-Accelerated RL Training via JAX (XLRON)
Implementing both the simulation environment and the RL algorithm in JAX lets the entire training loop — environment stepping, reward computation, policy updates — JIT-compile into a single program deployable to GPU/TPU. This requires expressing the simulator as pure functions over fixed-shape arrays (functional programming, no stateful objects), enabling `vmap`-style vectorization of hundreds to thousands of parallel environment instances on one GPU, reported to deliver 100-1000x training speedups over CPU-cluster approaches, with larger relative speedups at larger network/FSU-count scales.

## Software Engineering Rigor for RL Research Reproducibility
Addressing reproducibility gaps caused by closed-source implementations and absent test coverage in optical-network RL research, tools like XLRON apply test-driven development (hundreds of unit tests), modular/extensible design, and command-line reproducibility with controlled random seeds — positioning such libraries as standardized, trustworthy environments (RMSA, RSA, RWA, VONE) reducing duplicated reimplementation across research groups. Benchmark topologies like NSFNET (14 nodes, mid-size) and CONUS (75 nodes, large-scale) are used to validate both algorithm quality and scalability of the accelerated training approach.

## Optical Network Failure Management (ONFM)
ONFM covers estimating quality of transmission (QoT) before deployment, and detecting, predicting, identifying, localizing, and sizing failures once a lightpath is in service. Traditional ONFM relies on manual troubleshooting and rule-based thresholding; ML-based ONFM instead learns signatures in monitored data (BER, OSNR, alarms, spectral traces) to automate these decisions across WDM, EON, OTN, PON, and FSO technologies, requiring design choices about what data to collect, where to monitor, which failure types to target, and what time horizon to use.

## QoT Estimation
QoT estimation predicts whether a candidate lightpath will meet transmission-quality requirements (OSNR, GSNR, Q-factor, BER) before provisioning. Analytical physical-layer models (e.g., the GN-model of nonlinear propagation) must add conservative margins to cover uncertain parameters (connector losses, EDFA gain ripple, exact fiber length/type), wasting spectral/transponder resources; ML-based QoT estimation instead learns the feature-to-QoT mapping from historical data (implicitly capturing these uncertainties), or uses "input refinement" hybrid approaches where ML corrects only the uncertain parameters feeding an analytical model.

## Failure Detection, Prediction, Identification, Localization, and Magnitude Estimation
These ONFM sub-tasks address, respectively: is there a failure now (detection), will there be one (prediction), what caused it (identification/root-cause — filter shift, EDFA malfunction, laser drift, fiber bend), where is it (localization via alarm correlation or graph-based models), and how severe is it (magnitude estimation). ML extracts hidden signatures (mean, variance, temporal trend) from monitored QoT metrics that raw threshold-crossing cannot distinguish; most models are trained/evaluated for one task/failure-type/magnitude in isolation, so generalizing across simultaneous variations remains an open problem.

## Hard vs. Soft Failures
Hard failures are sudden, catastrophic, unpredictable events (fiber cuts) typically handled via abrupt-change/anomaly detection. Soft failures are gradual degradations (slow filter drift, aging components) that develop over time, harder to detect with fixed thresholds and better suited to trend analysis and early-warning prediction. Concurrent (simultaneous) failures further complicate both categories since their combined effect on monitored parameters differs from single-failure training data.

## Active Learning and Data Scarcity Mitigation (Augmentation, Digital Twins, Transfer Learning)
Active learning uses a preliminary model to score unlabeled/probe-generated data by prediction confidence, prioritizing the most informative points for labeling — reducing the number of costly probe lightpaths needed for representative training sets. Because real failure data is scarce (failures are rare relative to normal operation), complementary strategies include synthetic data augmentation (VAEs, GANs, SMOTE for balancing minority-failure classes), digital twins (simulated/lab-replica network counterparts generating labeled failure data under controlled conditions), and transfer learning/domain adaptation (reusing a data-rich source domain's knowledge to bootstrap a data-poor target), often combined with semi-supervised learning to auto-annotate larger unlabeled pools.

## Continual Learning and Data/Model Drift
The statistical relationship between network features and failure labels can change over a network's lifetime (data drift) due to equipment aging or shifting traffic/conditions, making static models stale. Continual learning periodically updates deployed models with new data, though open questions remain on retraining frequency, required new-data volume, and avoiding catastrophic forgetting of previously learned failure patterns.

## Federated Learning (Horizontal and Vertical) for Privacy-Preserving ONFM
Federated learning lets multiple operators/vendors jointly train a model without centrally sharing raw, confidentiality-sensitive network data. Horizontal FL applies when parties hold different data instances but the same feature set (e.g., multiple vendors sharing alarm-based data for failure identification); vertical FL applies when parties hold different features of the same data instances (e.g., different operators each monitoring a different lightpath segment), useful for collaborative localization — often combined with encryption (homomorphic encryption, distributed PCA) for further privacy protection.

## Uncertainty Quantification, Conformal Prediction, and Explainable AI (XAI/SHAP)
Because misclassified failure causes/severities can trigger costly unnecessary interventions, models should output confidence alongside predictions: uncertainty quantification attaches a numerical confidence score, and conformal prediction produces statistically-guaranteed prediction sets/intervals rather than point estimates. XAI provides human-interpretable explanations for trust and troubleshooting; SHAP (SHapley Additive exPlanations) computes each feature's marginal contribution via cooperative-game-theory Shapley values, ranking features by global importance and showing per-point whether a feature pushed a prediction toward or against a class — applied across QoT misclassification, failure detection, laser-lifetime prediction, and fault localization.

## ML Algorithm Selection, Public Datasets, and Model Generalization
ONFM draws on both supervised (regression, NN, SVM, tree-based) and unsupervised (K-means, isolation forest, DBSCAN) algorithms depending on label availability and data structure, with tree-based models favored for tabular data and neural networks (RNN/attention) favored for sequential/spatial correlation. Because most failure data is proprietary, only a handful of public datasets exist for benchmarking (synthetic QoT generators, the Sant'Anna Optical Failure Dataset, Fraunhofer WDM scenario data, OTDR-trace datasets), and models trained for one topology/scenario tend to overfit, motivating localized (rather than whole-network) features, online-learning fine-tuning, and richer simulation/field-trial validation to close the sim-to-real gap.

## Hollow-Core Fiber (HCF)
HCF guides light through a near-vacuum hollow core (antiresonant/nested nodeless structures) instead of solid silica, offering potentially lower attenuation (below 0.11 dB/km), a wider low-loss spectral window favoring ultra-wideband transmission, and roughly 33% lower latency since light travels faster through near-vacuum than glass. Negligible Kerr nonlinearity and absent stimulated Raman scattering (SRS) allow much higher per-channel launch powers without nonlinear degradation, but manufacturing uncertainty, higher connector/splice losses, and a new noise term (inter-modal interference) currently limit its competitiveness against mature silica fibers.

## Inter-Modal Interference (IMI) and Generalized SNR (GSNR)
IMI is an HCF-specific penalty from higher-order spatial modes leaking power into the fundamental mode, negligible in solid-core fibers, behaving as an added noise term whose magnitude (roughly -40 to -60 dB/km depending on fiber maturity) must drop below about -60 dB/km to become performance-irrelevant. GSNR is the standard physical-layer QoT metric — channel power divided by the sum of ASE noise, nonlinear interference, and (uniquely for HCF) IMI power — with end-to-end GSNR obtained by inverse-summing per-span contributions plus transceiver/ROADM penalties, used to assess network-level feasibility against a required OSNR threshold.

## Optical Amplification and Multiband Transmission for HCF vs. Silica Fiber
EDFAs are the mature, cost-effective amplification standard; hybrid EDFA/Raman amplification (HFA) further boosts silica-fiber performance by lowering required launch/EDFA gain via counter-propagating Raman pumps, but HCF has no meaningful Raman gain medium so cannot use HFA, relying solely on high-power, low-noise EDFAs. Multiband transmission (extending beyond C-band into L-band/ultra-wideband) intensifies silica fiber's SRS power-tilt effect, requiring complex optimization, whereas HCF's SRS-immunity makes its relative advantage over silica grow as the transmission band widens — quantified via a "parity curve" mapping the (attenuation, connection-loss) boundary where HCF matches a reference fiber's GSNR, complemented by full network-level routing/spectrum-assignment simulation to translate span-level gains into carried-traffic capacity gains.

## Passive Optical Networks (PON) and Short-Reach Optical Systems
Short-reach optical links (up to ~100 km — inter-data-center, access/LAN, industrial automation) prioritize low latency and cost over long-haul reach. PONs use passive optical splitters/combiners to share fiber cost-effectively, but power-budget losses limit user count and reach, and chromatic dispersion/nonlinearity further constrain reach for high-baud-rate intensity-modulated links, motivating ML-based DSP to relax these physical constraints without added hardware cost.

## Intensity Modulation with Direct Detection (IMDD) vs. Coherent Detection
IMDD encodes information in real-valued, positive optical intensity and recovers it with a simple photodiode, avoiding local oscillators/phase-diversity optics — low complexity, robust to phase noise/polarization effects, cost-effective, but lower capacity per fiber than coherent detection. Coherent systems linearly recover the complex baseband optical field via phase-diversity receivers, enabling advanced modulation, polarization multiplexing, and DWDM/multi-terabit super-channels, at greater hardware/processing cost; both introduce distinct nonlinear effects (SPM/XPM/FWM for coherent) that ML-based equalizers increasingly mitigate.

## PON-Specific ML Applications (Bandwidth Prediction, Subcarrier Allocation, Fault Detection)
Bandwidth request/prediction forecasts near-future available bandwidth so DBA schemes can proactively serve ONUs (via k-NN, feed-forward ANN, or XGBoost). Dynamic subcarrier allocation (DSA) in OFDM-based PONs uses DRL/MAC-layer algorithms to share subcarriers based on real-time demand, often formulated as an ILP over latency/throughput/energy. Fault detection learns historical fault patterns (random forests, ANNs, hybrid double-exponential-smoothing + SVM, Bayesian networks) to proactively identify fiber cuts, equipment faults, and ONU malfunctions despite overlapping reflection signatures from near-equidistant terminations, enabling predictive rather than reactive maintenance.

## Classical Equalizers: Zero-Forcing, FFE/DFE, Viterbi, Volterra
Zero-forcing removes ISI by inverting the channel's frequency response but amplifies noise at spectral "valleys." Feed-forward (FFE) and decision-feedback (DFE) equalizers process signals with only forward or additional feedback-based ISI cancellation (DFE risks error propagation). The Viterbi equalizer finds the most likely transmitted sequence via dynamic programming over a trellis (near-optimal but O(T·N²) complexity). The Volterra series equalizer models nonlinear distortion via hierarchical nonlinear filter kernels (first-order linear, higher-order nonlinear), the classical nonlinear-equalization benchmark for PAM4/IMDD systems, often too complex for cost-sensitive PON receivers relative to lighter ML alternatives.

## Adaptive Filtering
Adaptive filters iteratively adjust coefficients to minimize error between desired and actual output, tracking time-varying channel characteristics rather than assuming a fixed model; FFE/DFE are specific adaptive-filter instances. With t taps, per-iteration update complexity is O(t) — the baseline against which more complex nonlinear/ML equalizers are compared.

## Recurrent Architectures for Equalization (RNN, LSTM, GRU)
RNNs process sequential signals under a Markov-like assumption (current hidden state depends only on the previous state and input), naturally suited to communication signals, but suffer exploding/vanishing gradients during backpropagation through time. LSTM's cell state with input/forget/output gates and GRU's simplified update/reset gates mitigate this, both widely used for chromatic dispersion and nonlinearity compensation in short-reach coherent/IMDD links, often exceeding Volterra/Viterbi benchmark performance.

## CNNs and Fiber/Channel Distortion Models (CD, Jitter, Chirp)
CNNs apply weight-sharing convolutional kernels to extract position-invariant local temporal features (with multi-scale inception modules and 1×1 channel-reduction convolutions), offering better parameter efficiency and hardware-friendly parallelism than RNN/LSTM for equalization. Chromatic dispersion is a linear, frequency-dependent diffusion-like effect attenuating high-frequency signal components; jitter is Gaussian-distributed timing noise corrupting high-frequency content; chirp is time-varying instantaneous frequency — together these couple time- and frequency-domain distortions non-independently, motivating hybrid time/frequency ML equalizer designs since no single-domain operation can fully invert them.

## Time-Series Model Taxonomy for Equalization
Equalization can be reframed as a general time-series forecasting/modeling problem, drawing on four families: traditional models (RNN/LSTM/GRU/CNN), Fourier convolution-based methods, transformer-based models, and temporal convolutional networks — allowing techniques from broader ML time-series research to be repurposed for channel-impairment compensation rather than requiring bespoke DSP designs.

## Temporal Convolutional Sampling Networks (SCINet/FC-SCINet, DLinear, LightTS)
FC-SCINet decomposes a signal into low/high-frequency components via a moving-average filter and recombines them with hierarchical odd/even downsampling and interacting nonlinear convolutions, achieving O(k) complexity independent of input length. DLinear similarly decomposes into trend and residual components combined linearly at O(k·n_s) complexity, a very low-complexity, high-performance baseline. LightTS uses interval and continuous sampling fed into an MLP-based Information Exchange Block. All three offer interpretable, hardware-friendly, low-parameter alternatives to LSTM with comparable or superior CD-mitigation performance in PON systems.

## Transformer Self-Attention and Efficient Variants
Scaled dot-product attention transforms each input into Query/Key/Value vectors, letting a model weigh relevance across all sequence positions rather than only recent history; multi-head attention runs several such computations in parallel, giving strong long-range dependency modeling at the cost of quadratic sequence-length complexity. Efficient variants (Reformer's LSH attention, Informer's low-rank query selection, Pyraformer's hierarchical pyramidal attention, FEDformer's Fourier/wavelet-domain attention, Autoformer's auto-correlation/series decomposition, Crossformer/Triformer's cross-dimension/patch-wise attention) trade complexity, periodicity-awareness, and cross-variable modeling for different sequence-length regimes relevant to equalization.

## Fourier-Domain Neural Networks (TimesNet, FreTS)
Since most real-world signals are band/low-pass and the Fourier transform is bijective and computable in O(n log n) via FFT, Fourier-domain models exploit this structure directly. TimesNet reshapes a 1D signal into 2D tensors using dominant Fourier frequencies, applies inception-style convolutions per scale, and reconstructs via amplitude-weighted attention across scales. FreTS performs frequency-domain MLP operations mathematically equivalent to global time-domain convolution, reducing effective complexity from O(n) to O(n log n) via reduced dynamic range — both capturing intra- and inter-periodic variation for equalization/time-series tasks.

## Complexity Analysis and Performance-vs-Complexity Trade-offs
Comparative Big-O analysis (O(t) for classical equalizers, O(T·N²) for Viterbi, O((d-1)n²) for DNNs, O(n_h²n_s)-type formulas for RNN/GRU/LSTM, O(n_o) for CNN) underlies the central concern of trading equalization accuracy against hardware feasibility at cost-sensitive PON ONUs. Different nonlinear equalizer families (FFNN, RBF-NN, AR-RNN, layer-RNN) present distinct trade-offs even with matched neuron counts — FFNN offers lowest complexity, AR-RNN offers superior performance — emphasizing that model selection must weigh accuracy gains against inference-time constraints rather than optimizing BER alone.

## Model Compression: Knowledge Distillation and Vector Quantization (VQ)
Knowledge distillation transfers a large "teacher" model's behavior into a smaller, more parallelizable "student" model, particularly valuable for RNN-based equalizers whose sequential feedback loops resist hardware parallelization; extensions handle limited/small time-series datasets via "privileged information" distillation. Vector quantization compresses representations by mapping inputs to a small codebook of prototype vectors (via k-means-style refinement), reducing inference memory/compute — both techniques (and their combination) target compact, edge/ONU-deployable equalizer models without significant performance loss.
